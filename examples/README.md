# Client config examples

Copy a file into your MCP client config and replace `<your-token>` with the Bearer token from [portal.thinkreview.dev/mcp](https://portal.thinkreview.dev/mcp).

| File | Client |
|---|---|
| `cursor.mcp.json` | Cursor |
| `claude.mcp.json` | Claude Code |
| `vscode-copilot.mcp.json` | GitHub Copilot (VS Code) |

Never commit a real token.
